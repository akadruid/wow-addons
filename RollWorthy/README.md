# RollWorthy（值得才ROLL）

不浪费 ROLL 币（晦暗虚空核心）：**只有你勾选的场景允许使用 ROLL 币，未勾选的场景直接跳过**——
不弹选项、也不花币。

- 账号级设置，**默认关闭**，需要手动开启
- 跳过时一定提示：只写进自己的聊天框，不广播到任何频道
- 只用安全后置钩子 + 暴雪自己的关闭流程，不替换暴雪脚本
- 与「真ROLL吗？」共存：跳过时不会再触发它的二次确认

## 配置：总开关 + 四组场景过滤

三层结构，极性如下：

1. **启用插件**：关闭时全部场景都按暴雪默认弹窗；打开后才按下面的过滤规则走。
2. **每组的过滤开关**（如「开启大秘境过滤」）：关闭＝这组完全不过滤，一律放行；打开＝按该组选择的最低门槛处理。过滤关闭时下拉框自动置灰。
3. **组内选择**：只选一个「最低门槛」，达到门槛及以上放行，低于门槛跳过。

| 场景 | 组开关（默认） | 最低门槛（默认） | 判定依据 |
| --- | --- | --- | --- |
| 大秘境 | 开 | **史诗及以下** / 2–15 层（10 层） | 弹窗 `difficultyID = 8`，`treasureContextLevel` = 钥石层数 |
| 团本 | 开 | 随机 / 普通 / 英雄（英雄） | 弹窗 `difficultyID` 17 / 14 / 15 / 16，按难度递增比较 |
| 世界 | 开 | 只有总开关，无难度可选 | 狩猎（`difficultyID = 14` + `itemContext = 55` + 狩猎任务）、世界首领 / Lair（`difficultyID = 250`）、时光漫游（24 / 33）、追随者地下城（205） |
| 地下堡 | 开 | **全不Roll** / 1–11 层（全不Roll） | 弹窗 `difficultyID = 208`，`treasureContextLevel` = 层数 |

- 团本不提供「史诗」选项，因为史诗永远在最低门槛之上、不会被过滤。
- 大秘境选「史诗及以下」时，除大秘境本身全放行外，还会把这些低档五人本一起跳过：
  史诗(23)、英雄(2)、普通(1)、追随者(205)、时光漫游(24 / 33)。
- 世界这一组只有总开关：开启＝整组跳过；关闭＝不拦截。组内包含：**狩猎**、**世界首领 / Lair 首领**（客户端里就是难度 250）、**时光漫游**（24 / 33）、**追随者地下城**（205）。
- 追随者地下城与时光漫游**只跟"世界"开关走**，不受大秘境那个「史诗及以下」选项影响（后者只覆盖 普通 / 英雄 / 史诗(M0) 五人本）。
- 世界组**不含**弹性史诗团本（233）。注意：233 目前没有归入任何组，所以它不会被阻止——我们对它没有任何判定逻辑，只是没碰它。
- 狩猎弹窗的难度 ID 和普通团本相同（都是 14），所以它不靠难度 ID 识别，而是靠 `itemContext = 55`（狩猎掉落池，VoidcoreHelper 也是用 55 取这个池子）＋「当前有狩猎目标」＋「不在团本实例」三个条件。
- 地下堡选「全不Roll」时，地下堡一律跳过（不看层数）。

**上面四类以外的场景不会阻止**：五人本、追随者地下城、时光漫游，以及以后新增、暂未收录的场景，
统统按暴雪默认弹出。

判定拿不到层数 / 难度时会放行，避免误吞机会；狩猎比较特殊，`250` 但难度取不到时按"未勾选"跳过。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/rw` | 查看守门状态与最近一次弹窗 |
| `/rw on` / `/rw off` | 开关守门 |
| `/rw test` | 在自己聊天框写一行示例提示（自检） |
| `/rw debug` | 输出开关、钩子状态、最近一次弹窗的**原始数值**和判定结果 |

`/rw` 也可以写作 `/rollworthy`。

## 安装

把 `RollWorthy` 目录放到：

```text
World of Warcraft/_retail_/Interface/AddOns/RollWorthy
```

## 测试步骤

1. `/rw` 默认输出 `值得才ROLL：关闭`；先 `/rw on` 或到设置面板打开总开关。
2. 换角色后再看 `/rw`，状态和勾选应保持不变（账号级设置）。
3. `/rw test` 只在自己聊天框出现一行红色 `已跳过 ROLL 币：…`；队友看不到任何内容。
4. 普通 / 随机团本击杀首领：不出现 ROLL 币窗口，聊天框提示 `已跳过 ROLL 币：普通团本`。
5. 英雄 / 史诗团本击杀首领：正常出现 ROLL 币窗口；装了「真ROLL吗？」时它的二次确认照常工作。
6. 大秘境低于设定层数打完：不出现 ROLL 币窗口；达到层数正常出现。
7. 地下堡选"不勾选"进去打完：不出现 ROLL 币窗口；勾选且层数达标后正常出现。
8. 狩猎：勾选对应难度才会放行（难度判定见下）。
9. `/rw debug` 会打印 `difficulty / itemContext / treasureLevel / displayItem` 四个原始值，用来校准。

## 待校准项

狩猎的难度映射（`250` + `1/2/3` = 普通/困难/梦魇）目前只有一条存档旁证，做法是：
进一次狩猎，打完看 `/rw debug` 输出的 `treasureLevel`，确认普通/困难/梦魇分别对应 1/2/3；
如果对不上，改 `Core.lua` 里的 `HUNT_NORMAL / HUNT_HARD / HUNT_NIGHTMARE` 三个常量即可。

改动 `.lua` 内容 `/reload` 生效；改动 `.toc` 文件清单需要完全退出游戏再启动。
