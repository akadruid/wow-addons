# 游戏内测试步骤

## 本机路径

当前开发目录：

```text
E:\ai\wow-plugging\AzerothAssistant
```

本机正式服插件目录：

```text
D:\game\World of Warcraft\_retail_\Interface\AddOns
```

## 手工部署

本项目不使用目录联接，部署和覆盖由用户手工完成。

目标目录：

```text
D:\game\World of Warcraft\_retail_\Interface\AddOns\AzerothAssistant
```

目标目录中应直接包含：

```text
AzerothAssistant.toc
Bindings.xml
Config.lua
Core.lua
Locales.lua
MeetingStone.lua
Roster.lua
Runestone.lua
Talk.lua
UI.lua
```

本项目已经改名，首次部署新版本时应移除旧的 `GuildPartyInviter` 目录，避免两个版本同时加载。

## 首次加载

1. 完全退出魔兽世界。
2. 手工覆盖或部署 `AzerothAssistant` 目录。
3. 重新启动正式服。
4. 在角色选择界面的插件列表中确认 `Azeroth Assistant / 艾泽拉斯助手` 已启用。
5. 进入游戏后开启 Lua 错误显示：

```text
/console scriptErrors 1
```

6. 本机已经安装 `BugSack` 和 `BugGrabber`，如果出现报错，优先查看 BugSack。

## 基础检查

依次输入：

```text
/aa
/aa rune
/dump GetBindingKey("AZEROTHASSISTANT_RANDOM_INVITE")
/dump C_VignetteInfo.GetVignettes()
```

预期：

- `/aa` 打开公会成员窗口。
- 屏幕上方中心偏左出现并排的 `[邀]` 和 `[符]` 小型文字按钮。
- `/aa rune` 根据当前位面输出符文石事件是否激活。
- `GetBindingKey` 在设置快捷键前为空，设置后返回按键名称。
- `GetVignettes()` 返回当前客户端和位面的 Vignette GUID 列表。

## 快捷键测试

1. 按 `ESC` 打开选项。
2. 进入“按键设置”。
3. 找到“插件 -> 艾泽拉斯助手 -> 邀请首位符合条件的公会在线成员”。
4. 设置一个不会和现有功能冲突的按键。
5. 关闭设置窗口。
6. 关闭主窗口，直接按该快捷键。

预期：

- 邀请当前列表中首位符合条件的公会在线成员。
- 如果对方拒绝或已经退组，可以再次邀请同一个成员。
- 邀请快捷键可通过鼠标提示确认。

如果按键分类仍然没有显示，先确认游戏已经完全重启，而不是只执行 `/reload`。新增或重命名 `.toc`、XML 文件后必须重启客户端。

## 快捷栏测试

默认位置：

```text
屏幕顶部中心向左 180 像素，向下 40 像素
```

测试步骤：

1. 左键点击 `邀`，确认首位邀请生效。
2. 左键点击 `符`，确认聊天框输出当前位面的符文石状态。
3. 右键任意按钮，确认快捷栏解锁。
4. 按住左键拖动任意按钮，确认两个按钮一起移动。
5. 右键再次点击，确认快捷栏锁定。
6. 输入 `/reload`，确认两个按钮仍在一起，位置和锁定状态都已保存。

也可以使用：

```text
/aa lock
/aa unlock
```

## 符文石状态测试

需要在永歌森林当前位面分别测试符文石已激活和未激活状态。

已激活状态的 tooltip 应只有：

```text
符文石
符文石状态：
```

此时插件预期输出：

```text
[符文石检测] 位面 1234：左中 已激活
```

未激活状态的 tooltip 应出现黄色提示：

```text
这个符文石需要充能！使用潜藏奥能为其充能。
```

此时插件预期输出：

```text
[符文石检测] 位面 1234：未激活
```

如果 Vignette 存在但 tooltip 文本无法读取，预期输出：

```text
[符文石检测] 位面 1234：状态未知
```

没有检测到任何符文石：

```text
[符文石检测] 位面 1234：不存在
```

自动检测应在以下场景触发，并且仅在永歌森林内输出：

- 登录上线
- 进入永歌森林
- 加入队伍
- 离开队伍
- 位面实例变化

每次检测还会统计以下四个任务的接取数量：

```text
90574 血骑士
90573 魔导师
90575 远行者
90576 径巷之影
```

没有全部接取时额外输出：

```text
符文石任务缺失3/4
```

`3/4` 显示为红色，代表当前已经满足的任务数量。正在任务日志中或本周已经完成过，都计入数量；四项全部满足时不提醒。

同时执行下面的命令核对底层返回：

```text
/dump C_VignetteInfo.GetVignettes()
```

然后逐个执行：

```text
/dump C_VignetteInfo.GetVignetteInfo(vignetteGUID)
```

预期在返回值中看到以下任意 `vignetteID`：

```text
6951
6954
6955
6959
7130
```

如果符文石显然已经激活，但 Vignette ID 不在上述列表中，需要把原始返回发给开发侧更新模板。

如果需要在游戏内一次性输出所有符文石的 ID、坐标和状态，执行：

```text
/aa rune debug
```

输出格式：

```text
符文石 ID=6951 | 坐标 47.2, 59.1 | 状态=需要充能 | 地图显示=true | 已死亡=false
```

## 邀请边界测试

| 场景 | 预期 |
| --- | --- |
| 未加入公会 | 提示需要先加入公会，不能邀请 |
| 不是队长 | 提示没有邀请权限 |
| 小队已有 5 人 | 提示小队已满 |
| 当前在团队中 | 提示先转换为小队 |
| 公会没有符合条件的在线成员 | 提示没有可邀请成员 |
| 已在小队中的公会成员 | 列表中可见，但不可勾选 |
| 对方拒绝后再次邀请 | 小队状态校验通过后，可以重新邀请同一人 |
| 退组后再次邀请 | 成员不再被视为已在小队，可以重新邀请 |

## 快速离队测试

在按键设置中找到：

```text
插件 -> 艾泽拉斯助手 -> 无需确认直接离开当前小队
```

测试场景：

| 场景 | 预期 |
| --- | --- |
| 单人 | 提示当前没有小队 |
| 小队中 | 无确认弹窗，直接离开 |
| 团队中 | 只提示已阻止操作，不离队 |

也可以通过命令测试：

```text
/aa leave
```

## 集合石收藏测试

前置条件：已安装并启用 `MeetingStone`。

1. 执行 `/aa stone` 打开收藏窗口。
2. 确认默认列表包含 `3-78-676-0`。
3. 打开集合石搜索下拉框，确认“最近搜索”中出现“火焰之地”。
4. 换一个角色重复检查，确认同一收藏同样出现。
5. 执行 `/aa stone off`，确认收藏从最近搜索中消失。
6. 执行 `/aa stone on`，确认收藏重新出现。

增加其他副本时：

1. 在集合石中搜索目标副本。
2. 执行 `/aa stone addcurrent`，或打开 `/aa stone` 点击“收藏当前搜索”。
3. 确认窗口列表显示解析后的副本名称。

命令测试：

```text
/aa stone add 火焰之地
/aa stone list
/aa stone remove 2
/aa stone reset
```

移除 `AzerothAssistant` 或关闭该功能后，集合石自身保存的最近搜索数据不应发生变化。

## 任务对话自动选择测试

前置条件：角色在银月城，任务日志中有 `狩猎：择优猎杀`（任务 ID `91277`）。

1. 输入 `/aa talk`，确认输出 `任务对话自动选择：开启`。
2. 与狩猎 NPC 对话。
3. 每一步预期在聊天框看到提示，并自动继续到下一步：

```text
已自动选择对话选项：你们提供的太无趣了。我要自己挑选猎物
已自动选择对话选项：利爪卡达尼
已自动选择对话选项：盘卷蛇岛
已自动选择对话选项：梦魇
```

4. 对话结束后，任务日志中应出现 `狩猎：利爪卡达尼（梦魇）`。

按住 `Shift` 打开同一个对话，应完全不自动选择，用于临时手动挑选其他猎物。

自动选择按对话选项 ID 匹配，四步分别是：

```text
134312  你们提供的太无趣了。我要自己挑选猎物
140843  利爪卡达尼
140847  盘卷蛇岛
134313  梦魇
```

如果某一步没有自动选择，先确认该步的选项 ID 是否仍与上表一致（客户端更新可能调整 ID），不一致时按上表替换 `Talk.lua` 里对应规则的 `optionID`。

关闭自动选择：

```text
/aa talk off
```

再次对话应完全手动。重新打开使用 `/aa talk on`。

## 设置面板测试

1. 执行 `/aa config`，或在 `选项 → 插件` 中找到 `艾泽拉斯助手`。
2. 确认三个开关的默认状态都是开启：

```text
公会邀请助手
符文石助手
自动蛇岛梦魇狩猎
```

逐项关闭后检查：

| 操作 | 预期 |
| --- | --- |
| 关闭公会邀请助手 | `邀` 消失，`/aa` 只输出"公会邀请助手已关闭"，快捷键邀请同样只输出提示 |
| 关闭符文石助手 | `符` 消失，进入永歌森林不再自动输出检测结果，`/aa rune` 只输出提示 |
| 关闭自动蛇岛梦魇狩猎 | 与该 NPC 对话不再自动选择选项 |
| 两个快捷图标都关闭 | 整条快捷栏隐藏，`/reload` 后仍然隐藏 |
| 重新开启符文石助手 | `符` 重新出现，并立即触发一次检测 |

命令与面板应当同步：

```text
/aa talk off
```

执行后在面板中确认"自动蛇岛梦魇狩猎"已取消勾选；在面板中重新勾选后，`/aa talk` 输出应为"任务对话自动选择：开启"。

## 代码改动后的测试

修改代码后：

1. 手工将最新开发文件覆盖到游戏插件目录。
2. 只修改已有 Lua 文件时，可以输入 `/reload`。
3. 修改 `.toc`、XML、目录名或新增文件时，完全退出游戏后重新启动。
4. 再次执行 `/aa` 和 `/aa rune` 测试。

## 反馈问题时需要提供

- 正式服版本号
- 当前位面的地图事件状态
- 操作步骤
- 预期结果和实际结果
- BugSack 中的完整错误
- `/dump C_VignetteInfo.GetVignettes()` 的返回
- 符文石 Vignette 的 `C_VignetteInfo.GetVignetteInfo(vignetteGUID)` 返回
