# 游戏内测试步骤

## 部署

开发目录：

```text
E:\ai\wow-addons\Cheeser
```

正式服插件目录：

```text
D:\game\World of Warcraft\_retail_\Interface\AddOns\Cheeser
```

目录里应包含 `Cheeser.toc`、`Bindings.xml`、`AutoBuy.lua`、`AutoBuyMerchantUI.lua`、`Config.lua`、`Core.lua`、`Locales.lua`、`MeetingStone.lua`、`Roster.lua`、`Runestone.lua`、`Talk.lua`、`UI.lua`、`WarbandBank.lua`。

部署前确认插件目录中只有一份 `Cheeser`，移除可能残留的旧目录。

## 首次加载

1. 完全退出魔兽世界。
2. 覆盖部署 `Cheeser` 目录。
3. 启动正式服。
4. 在插件列表确认 `Cheeser` 已启用。
5. 进游戏开启 Lua 错误显示：

```text
/console scriptErrors 1
```

## 基础检查

依次输入：

```text
/che
/che buy
/che rune
/dump GetBindingKey("CHEESER_RANDOM_INVITE")
/dump C_VignetteInfo.GetVignettes()
```

预期：

- `/che` 打开设置面板。
- `/che buy` 打开设置面板中的商人自动购买部分。
- 屏幕顶部左侧出现 `[邀] [符]` 两个文字按钮。
- `/che rune` 输出当前位面符文石状态（一个周常都没接时只输出 `符文石任务缺失0/4`）。
- `GetBindingKey` 在设置快捷键前为空，设置后返回按键名。

## 快捷键

1. `ESC → 按键设置 → 插件 → Cheeser`。
2. 给“邀请首位符合条件的在线成员”和“无需确认直接离开当前小队”各设一个按键。
3. 直接按邀请键，确认邀请首位生效；按离队键，确认无确认弹窗离队（团队中应只提示不离队）。

## 快捷栏

- 左键 `邀` 邀请首位，左键 `符` 查询符文石。
- 右键解锁，拖动移动，再右键锁定；`/reload` 后位置与锁定状态应保留。
- 两个图标都关闭时整条快捷栏隐藏。

## 符文石状态

- 未接任何周常：只输出 `符文石任务缺失0/4`，不输出状态。
- 已接或已完成：输出 `不存在 / 未激活 / 位置 已激活` 及缺失数量。
- 手动 `符` 或 `/che rune`，开启“符文石状态通报小队”后应把状态发到小队（自动检测不通报），且小队消息以 `[Cheeser]` 开头。
- `/che rune debug` 输出每个符文石的 ID、坐标、状态。

自动检测触发点：登录、进入永歌森林、进/退队伍、位面变化。

## 邀请校验

| 场景 | 预期 |
| --- | --- |
| 未加入公会 | 提示需要先加入公会 |
| 不是队长 | 提示没有邀请权限 |
| 小队已满 | 提示小队已满 |
| 团队中 | 提示先转换为小队 |
| 无符合条件在线成员 | 提示没有可邀请成员 |

## 邀请来源（设置面板）

- 设置面板下拉框在“当前角色公会”和角色社区之间切换，选中后下拉框文字应即时更新。
- 战网社区不出现在列表。
- 在副本 / 团本等锁定状态下切到社区来源，应提示无法读取社区数据。

## 集合石收藏

1. 安装并启用 `MeetingStone`。
2. `/che stone` 打开收藏窗口，默认含 `1-397-1943-0`（永歌森林）。
3. 集合石“最近搜索”里应出现永歌森林，且换角色后仍存在。
4. `/che stone off` 后消失，`/che stone on` 后恢复。

## 任务对话自动选择

1. 角色在银月城，任务日志有 `狩猎：择优猎杀`（`91277`）。
2. `/che talk` 切换开关（输出 开启 / 关闭）。
3. 与狩猎 NPC 对话，自动依次选择四步并逐行提示。
4. 按住 `Shift` 对话应不自动选择。

## 商人自动购买

1. 全新安装时 `/che buy` 应显示“尚未选择物品”；填写物品 ID，或点“从背包选择”选择一件背包物品。
2. 全新安装时购买数量应默认为 `0`；完整设置和商人旁设置窗口都应显示“0 = 不限数量，买满即停”。
3. 设置购买数量为 `3`，手动打开出售该物品的商人；应只购买 3 件后停止。
4. 将购买数量改为 `0`，重新打开商人；应以批量请求持续购买，直到普通背包和钓鱼袋都没有可用空间。
5. 对使用其他货币或物品兑换的商人，确认持有量不足时停止，并确认启动提示中的货币数量按“单次兑换成本 × 计划份数”计算。
6. 在购买过程中关闭商人、切换到出售页、把相关货币或物品余额降到不足或清空商人库存，均应立即停止。
7. 背包选择列表应合并显示普通背包、材料包中的同 ID 物品，滚轮可滚动，点击物品行后设置框立即更新。
8. 完整设置和商人旁设置窗口都只保留物品、购买数量和功能开关，不再显示金币上限、保留空格或预览模式。
9. 商人窗口左侧应显示 `自动购买` 按钮；右键打开设置窗口，修改物品、数量和开关后，完整设置页应同步更新。
10. 左键快捷按钮开始购买；购买过程中按钮显示 `停止购买`，再次左键应立即停止后续批次，面板中的输入框应锁定。
11. 停止后按钮短暂显示 `正在停止...`，随后恢复为 `自动购买`；已提交的当前批次可能继续到账，但不应自动开始下一批。
12. 模拟一次购买超时或报错后，按钮恢复为 `自动购买`；再次左键应能从当前背包状态继续购买。
13. 关闭商人后，独立设置窗口应自动关闭；重新打开商人时，快捷按钮重新出现。

## 战团银行自动存放

1. 保持“自动存放战团绑定物品”开启，背包中准备可存入战团银行的战团绑定物品。
2. 通过便携战团银行打开 EllesmereUIBags 银行窗口；约半秒后应自动执行一次存放。
3. 在普通银行 NPC 处打开银行，再切换到“OneWarbank / All Warbank Tabs / 任一战团分页”；应自动执行一次存放。
4. 同一次银行会话中来回切换角色银行与战团银行视图，不应重复执行。
5. 关闭“自动存放战团绑定物品”后重新打开战团银行，不应触发存放。
6. 战斗中打开银行不应报错；离开战斗后可重新打开银行验证。
