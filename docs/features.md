# 艾泽拉斯助手功能说明

一款面向《魔兽世界》正式服的个人助手插件，集中处理常用的组队、区域事件查询和集合石搜索操作。

## 1. 公会快捷组队

用于快速邀请公会在线成员组建小队。

- `/aa` 打开公会在线成员列表。
- 自动排除自己、已在小队中的成员。
- 快捷键或按钮可直接邀请列表首位符合条件的成员。
- 邀请前自动检查队长权限、团队状态和剩余位置。
- 可设置快捷键，无需确认直接离开当前小队。
- 处于团队中时阻止离队操作，避免误触。

## 2. 保护符文石检测

用于判断当前位面的符文石是否已经充能激活。

- 识别永歌森林的 5 个符文石位置：左上、左中、中间、右下、左下。
- 未刷新时提示不存在，刷新但未充能时提示未激活。
- 已充能时显示具体位置和当前位面。
- 登录、进入永歌森林、加入队伍、离开队伍或位面变化时自动检测。
- 同时检查本周 4 个符文石周常，未全部满足时提示缺失数量。

## 3. 集合石最近搜索收藏

为集合石的“最近搜索”增加账号级收藏，避免每个角色重复搜索。

- 收藏保存在账号级配置中，所有角色共享。
- 默认收藏火焰之地普通模式。
- 支持活动代码、名称关键字，或在集合石搜索后直接收藏当前搜索。
- 不修改集合石角色存档，也不改变集合石原有搜索历史。
- 可随时启用、关闭或移除收藏。

常用命令：

```text
/aa stone
/aa stone addcurrent
/aa stone add 火焰之地
/aa stone list
/aa stone off
/aa stone on
```

## 4. 任务对话自动选择

接了指定任务后，与 NPC 对话时自动选择固定选项，免去每次手点。

- 当前内置 `狩猎：择优猎杀`（任务 `91277`）：自动依次选择"自行挑选猎物 → 利爪卡达尼 → 盘卷蛇岛 → 梦魇"。
- 匹配的是选项文本关键词，不依赖客户端语言之外的额外数据。
- 第一步使用完整句子触发，后面的短关键词只在同一条对话链条里生效，避免在别的对话里误选。
- 对话时按住 `Shift` 可以临时跳过自动选择。
- 每一条对话链最多连续自动选择 10 次，任务对话结束后自动复位。

常用命令：

```text
/aa talk
/aa talk on
/aa talk off
/aa talk list
```

## 5. 设置面板

在 `选项 → 插件 → 艾泽拉斯助手` 中按模块开启或关闭功能，也可以用 `/aa config` 直接打开。改动立即生效，不需要重载界面。

| 开关 | 控制内容 | 关闭后的表现 |
| --- | --- | --- |
| 公会邀请助手 | `邀` 图标、邀请窗口、快捷键邀请 | 隐藏图标，`/aa` 与快捷键只输出提示 |
| 符文石助手 | `符` 图标、符文石与周常自动检测 | 隐藏图标，停止自动检测，`/aa rune` 只输出提示 |
| 自动蛇岛梦魇狩猎 | 任务对话自动选择 | 对话不再自动选择选项 |

两个快捷栏图标都关闭时，整条快捷栏自动隐藏，位置和锁定状态仍然保留。
