# Cheeser 功能说明

面向《魔兽世界》正式服的“逃课”小工具，把重复性操作压缩成快捷栏 + 常用命令。

## 1. 一键组队

- 快捷栏 `邀` 按钮或快捷键，自动邀请当前来源中首位符合条件的在线成员。
- 邀请来源在设置面板下拉框选择：当前角色公会，或账号下任意角色社区。
- 可选开启“自动接受来源成员的组队邀请”，只接受当前所选公会或角色社区成员发来的邀请，默认关闭。
- 自动排除自己、已在小队成员；邀请前校验队长权限、团队状态、剩余位置。
- 使用 `C_PartyInfo.InviteUnit`，保留暴雪原生确认流程。
- 战网社区没有队伍邀请入口，不列为可选来源。

## 2. 保护符文石检测

- 识别永歌森林的 5 个符文石位置：左上、左中、中间、右下、左下。
- 登录、进入永歌森林、进/退队伍、位面变化时自动检测。
- 一个周常都没接时只提示 `符文石任务缺失0/4`；已接或已完成则正常输出状态。
- 同时检查 4 个周常，未全部满足时提示缺失数量。
- 手动查询（`符` 或 `/che rune`）可开启“通报小队”。
- 通报到小队时加上 `[Cheeser]` 前缀，方便队友识别消息来源、顺带传播插件。

## 3. 集合石最近搜索收藏

- 账号级收藏，所有角色共享，不修改集合石角色存档。
- 默认收藏永歌森林 `1-397-1943-0`。
- 支持活动代码、名称关键字，或搜索后直接收藏当前搜索。

常用命令：

```text
/che stone
/che stone addcurrent
/che stone add 永歌森林
/che stone list
/che stone off / on
```

## 4. 任务对话自动选择

- 内置 `狩猎：择优猎杀`，自动选完四步：自行挑选猎物 → 利爪卡达尼 → 盘卷蛇岛 → 梦魇。
- 优先按对话选项 ID 匹配，取不到再退回文本关键词。
- 对话时按住 `Shift` 跳过；每条链最多自动选 10 次。
- `/che talk` 开关该功能。

## 5. 商人自动购买

- 首次使用时不预选物品；可在设置面板填写物品 ID，或打开背包物品列表直接选择。相同物品会合并为一行并显示总持有量。
- 只在你手动打开商人窗口、当前购买页出售该物品时启动，不会自动寻找或打开商人。
- 按商人允许的单次购买上限提交批量请求；若单次上限较低，则一轮最多提交 10 次，等待这批物品全部到账后再继续，避免逐件等待造成的约一秒延迟。
- 同时计算普通背包、钓鱼袋等适用背包中的空位，以及同物品未满堆叠可容纳的数量。
- 购买数量默认 `0`，表示不设数量上限并持续购买到背包填满；填写正整数则按指定数量购买。
- 金币和其他商人货币/物品成本均按实际余额检查。最终购买量取背包容量、购买数量、库存、金币和各币种余额中的最小值。
- 启动消息会列出金币及其他货币/物品成本，自动购买期间会确认本次购买产生的购买弹窗。
- 背包已满、库存不足、金币或其他货币不足、达到数量/金币上限、商人关闭或出现游戏错误时立即停止。
- 打开商人时，商人窗口左侧显示切换按钮：空闲时显示 `自动购买`，左键开始或继续；运行中显示 `停止购买`，再次左键立即停止后续批次和自动确认。
- 设置面板可在商人旁直接修改购买物品、数量、金币上限、保留空格、功能开关和预览模式，并与完整设置页共享同一份配置。
- 停止操作不会撤回已经提交给服务器的当前批次，因此该批物品仍可能短暂到账；面板在停止过程中短暂锁定，避免立即重启造成重复请求。

## 6. 战团银行自动存放

- 通过 EllesmereUIBags 打开便携战团银行时，自动执行一次“存放战团绑定物品”。
- 在普通银行 NPC 处切换到任一战团视图时也会触发；同一次银行会话只触发一次。
- 存放目标为 `Enum.BankType.Account`，沿用各战团银行分页的收取规则与空位限制。
- 成功触发后，在聊天框输出一行 Cheeser 提示；同一次银行会话不会重复提示。
- 默认关闭，可在 Cheeser 设置面板开启；未加载 EllesmereUIBags 时不会执行。

## 7. 设置面板

`选项 → 插件 → Cheeser`，或输入 `/che` 打开。

| 开关 | 控制内容 | 关闭后的表现 |
| --- | --- | --- |
| 公会 / 社区邀请助手 | `邀` 图标、邀请来源 | 隐藏图标，邀请只输出提示 |
| 自动接受来源成员的组队邀请 | 自动接受当前来源成员的组队邀请 | 保留暴雪原生邀请弹窗 |
| 符文石助手 | `符` 图标、自动检测 | 隐藏图标，停止自动检测，`/che rune` 只输出提示 |
| 符文石状态通报小队 | 手动查询时发送到小队 | 手动查询只显示给自己 |
| 自动蛇岛梦魇狩猎 | 任务对话自动选择 | 对话不再自动选择 |
| 商人自动购买 | 手动打开商人后逐件补满背包 | 不扫描商人、不购买 |
| 自动存放战团绑定物品 | 打开战团银行或切到战团页时存放一次 | 不自动调用银行存放 |

两个快捷栏图标都关闭时，整条快捷栏隐藏，位置和锁定状态仍保留。
