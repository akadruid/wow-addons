# 逃课助手功能说明

面向《魔兽世界》正式服的“逃课”小工具，把重复性操作压缩成快捷栏 + 常用命令。

## 1. 一键组队

- 快捷栏 `邀` 按钮或快捷键，自动邀请当前来源中首位符合条件的在线成员。
- 邀请来源在设置面板下拉框选择：当前角色公会，或账号下任意角色社区。
- 自动排除自己、已在小队成员；邀请前校验队长权限、团队状态、剩余位置。
- 使用 `C_PartyInfo.InviteUnit`，保留暴雪原生确认流程。
- 战网社区没有队伍邀请入口，不列为可选来源。

## 2. 保护符文石检测

- 识别永歌森林的 5 个符文石位置：左上、左中、中间、右下、左下。
- 登录、进入永歌森林、进/退队伍、位面变化时自动检测。
- 一个周常都没接时只提示 `符文石任务缺失0/4`；已接或已完成则正常输出状态。
- 同时检查 4 个周常，未全部满足时提示缺失数量。
- 手动查询（`符` 或 `/che rune`）可开启“通报小队”。

## 3. 集合石最近搜索收藏

- 账号级收藏，所有角色共享，不修改集合石角色存档。
- 默认收藏永歌森林 `1-397-1943-0`。
- 支持活动代码、名称关键字，或搜索后直接收藏当前搜索。

常用命令：

```text
/che stone
/che stone addcurrent
/che stone add 永歌森林
/che stone list
/che stone off / on
```

## 4. 任务对话自动选择

- 内置 `狩猎：择优猎杀`，自动选完四步：自行挑选猎物 → 利爪卡达尼 → 盘卷蛇岛 → 梦魇。
- 优先按对话选项 ID 匹配，取不到再退回文本关键词。
- 对话时按住 `Shift` 跳过；每条链最多自动选 10 次。
- `/che talk` 开关该功能。

## 5. 设置面板

`选项 → 插件 → 逃课助手`，或输入 `/che` 打开。

| 开关 | 控制内容 | 关闭后的表现 |
| --- | --- | --- |
| 公会 / 社区邀请助手 | `邀` 图标、邀请来源 | 隐藏图标，邀请只输出提示 |
| 符文石助手 | `符` 图标、自动检测 | 隐藏图标，停止自动检测，`/che rune` 只输出提示 |
| 符文石状态通报小队 | 手动查询时发送到小队 | 手动查询只显示给自己 |
| 自动蛇岛梦魇狩猎 | 任务对话自动选择 | 对话不再自动选择 |

两个快捷栏图标都关闭时，整条快捷栏隐藏，位置和锁定状态仍保留。
