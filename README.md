# Azeroth Assistant

中文名：**艾泽拉斯助手**

面向《魔兽世界》正式服的私人多功能插件。当前包含公会小队邀请与地图事件状态查询，后续继续在同一条快捷栏中扩展其他功能。

作者：[akadruid](https://github.com/akadruid) · 仓库：[akadruid/wow-addons](https://github.com/akadruid/wow-addons) · 许可：[MIT](LICENSE)

当前开发基线：

- 正式服 `12.1.0 (69814)`
- TOC `Interface: 120100`
- 主要面向 `zhCN` 客户端，同时保留 `enUS` 回退文本

## 当前功能

### 快捷栏

默认在屏幕上方中心偏左显示两个并排的小型文字按钮：

```text
[邀] [符]
```

- 两个按钮可以分别在设置面板中关闭；都关闭时整条快捷栏自动隐藏。
- `邀`：邀请当前来源列表中首位符合条件的在线成员（公会或角色社区）。
- `符`：查询当前位面的保护符文石地图事件是否已经激活。
- `符` 字颜色表示符文石状态：灰色表示不存在，黄色表示未激活，绿色表示已激活。
- 按钮按文字实际宽度自动收紧，无背景、无边框，只显示文字缩写。
- 两个文字按钮之间只保留一个汉字的宽度。
- 字体大小为 `20`，保留描边。
- 已锁定时文字完全不透明，解锁后整体降低透明度，表示可以拖动。
- 右键任意按钮：锁定或解锁快捷栏。
- 解锁后拖动任意按钮：移动整个快捷栏并保存位置。

### 设置面板

打开方式：`选项 → 插件 → 艾泽拉斯助手`，或直接输入 `/aa config`。

面板里按模块提供开关，改动立即生效：

| 开关 | 关闭后的表现 |
| --- | --- |
| 公会 / 社区邀请助手 | 隐藏 `邀` 图标，`/aa` 不再打开邀请窗口，快捷键邀请只输出提示 |
| 符文石助手 | 隐藏 `符` 图标，不再自动检测符文石，`/aa rune` 只输出提示 |
| 自动蛇岛梦魇狩猎 | 对话不再自动选择选项 |

面板里还有一个“邀请来源”下拉框，用来在“当前角色公会”和任意一个角色社区之间切换；切换后邀请窗口、状态行和快捷键邀请都会立即改用新来源。等价命令见下面的 `/aa source`。

面板底部还有一个“打开公会邀请窗口”按钮，方便在关闭图标后仍然手动打开一次。

### 公会邀请

- `/aa`、`/assistant` 或兼容命令 `/gpi` 打开公会成员窗口。
- 在按键设置中为“邀请首位符合条件的公会在线成员”绑定快捷键。
- 列出公会在线成员，支持搜索、职业颜色、等级、区域和在线状态显示。
- 邀请来源可切换：默认读取当前角色公会，也可以改成账号下任意一个角色社区。
- 社区成员使用 `C_Club` 读取，列表同样显示职业颜色、等级、区域和在线状态。
- 战网社区没有队伍邀请入口，因此不会出现在可选来源里。
- 先检查小队状态，再排除自己、已经在小队中的成员和当前无可邀请位置的情况。
- 按小队剩余空位限制选择人数。
- 使用 `C_PartyInfo.InviteUnit`，保留暴雪原生确认流程。

### 快速离队

- 在按键设置中绑定“无需确认直接离开当前小队”。
- 小队中触发时使用 `C_PartyInfo.ConfirmLeaveParty()`，不再弹出确认。
- 团队中使用时只输出提示，不执行任何离队操作，避免误触。
- 单人状态下只提示当前没有小队。
- 也可以使用命令 `/aa leave`。

### 保护符文石状态

- 点击快捷栏中的符文石图标查询当前位面状态。
- 符文石是独立 Vignette 地图事件，不是 `萨瑟利尔的聚会`，也不按周常任务状态判断。
- 当前客户端共有 5 个符文石 Vignette 模板：`6951、6954、6955、6959、7130`。
- 调用 `C_VignetteInfo.GetVignettes()` 读取当前位面正在激活的地图事件。
- Vignette 存在只说明符文石在地图上刷新，还需要读取它绑定的 tooltip widget。
- Tooltip 中出现“需要充能／潜藏奥能”时，表示符文石尚未激活。
- Tooltip 中没有上述提示时，表示该符文石已经激活。
- 聊天框只输出简洁状态，不显示坐标和 ID。
- `左中`、`右下` 等位置名称显示为黄色，`已激活` 显示为绿色。
- 插件消息会写入所有已创建的聊天标签页，不再只写入默认综合窗口。

标准输出：

```text
[符文石检测] 位面 1234：不存在
[符文石检测] 位面 1234：未激活
[符文石检测] 位面 1234：左中 已激活
```

位置映射：

| Vignette ID | 位置 |
| --- | --- |
| `7130` | 左上 |
| `6951` | 左中 |
| `6955` | 中间 |
| `6954` | 右下 |
| `6959` | 左下 |

每次检测还会检查四个周常任务是否已接：

```text
90574 加固符文石：血骑士
90573 加固符文石：魔导师
90575 加固符文石：远行者
90576 加固符文石：径巷之影
```

如果没有全部接取，会额外输出：

```text
符文石任务缺失3/4
```

其中 `3/4` 表示已经满足的数量，使用红色显示。判断规则是：

```text
任务正在任务日志中
或
本周已经完成过该任务
```

任一条件成立都计入已满足数量。四项全部满足时不输出提醒。

该查询不判断周常任务是否接取、是否完成，只判断当前位面随机刷新的符文石是否已经充能激活。

### 集合石最近搜索收藏

- 为集合石增加账号级“最近搜索”收藏。
- 收藏只在运行时与当前角色的真实搜索历史合并，不写入每个角色的集合石存档。
- 所有角色、所有服务器共享同一份收藏。
- 默认加入火焰之地普通：`3-78-676-0`。
- 支持活动代码或名称关键字，名称会通过 `C_LFGList.GetAvailableActivities` 解析。
- 未安装集合石时模块保持空闲，不会产生报错。

使用 `/aa stone` 打开配置窗口，或使用命令：

```text
/aa stone addcurrent
/aa stone on
/aa stone off
/aa stone list
/aa stone add 3-78-676-0
/aa stone add 火焰之地
/aa stone remove 1
/aa stone reset
```

最省事的方式：先在集合石中正常搜索目标副本，再打开 `/aa stone` 点击“收藏当前搜索”，或执行 `/aa stone addcurrent`。

### 任务对话自动选择

- 接了 `狩猎：择优猎杀` 之后，与狩猎 NPC 对话时按顺序自动选择：
  - `你们提供的太无趣了。我要自己挑选猎物`
  - `利爪卡达尼`
  - `盘卷蛇岛`
  - `梦魇`
- 四步分别对应对话选项 ID `134312 → 140843 → 140847 → 134313`，优先按 ID 匹配，取不到 ID 时才退回文本关键词，避免客户端文本差异导致失效。
- 第一步使用完整句子作为触发条件，后面的关键词只在同一条任务对话链条里生效，避免在别的对话里误选。
- 每自动选择一步，聊天框输出一行提示。
- 对话时按住 `Shift` 可以跳过自动选择。
- 每一步最多连续自动选择 10 次，防止脚本失控。

## 命令

```text
/aa
/assistant
/gpi
```

锁定快捷栏：

```text
/aa lock
/aa unlock
```

直接查询符文石：

```text
/aa rune
```

输出每个符文石的 ID、实时坐标和状态：

```text
/aa rune debug
```

任务对话自动选择：

```text
/aa talk
/aa talk on
/aa talk off
/aa talk list
```

切换邀请来源：

```text
/aa source list
/aa source guild
/aa source 2
/aa source 火焰之地
```

`/aa source list` 会输出编号列表，`1` 是当前角色公会；也可以直接写公会名或社区名（支持部分匹配）。列表和提示里的名称会带上 `（公会）` / `（社区）` 后缀，公会与社区同名时也能区分。

打开设置面板：

```text
/aa config
```

无需确认直接离开小队：

```text
/aa leave
```

## 开发状态

- 公会邀请功能已经可以在游戏内点击使用。
- 邀请来源支持“当前角色公会”和“角色社区”，可在设置面板或用 `/aa source` 切换；战网社区没有队伍邀请入口，不在可选范围内。

- 人物位于永歌森林时，登录、进入区域、加入队伍、离开队伍和位面变化会自动触发检测。
- 三个模块的开关已经接入 `选项 → 插件 → 艾泽拉斯助手`，改动立即生效。
- 任务对话自动选择已内置 `狩猎：择优猎杀` 的四步选项，还需要在游戏内确认这四个选项属于普通对话选项界面。
